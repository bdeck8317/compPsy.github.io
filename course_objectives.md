## Course Objectives

By the end of this course, you should be able to:
1.	Understand the basic logic of programming and how it supports data analysis, statistics, visualization, and reproducible research in psychology and brain science.
2.	Write simple, well-commented scripts in either R or Python, and read basic code examples in both languages.
3.	Work with simple datasets by importing, inspecting, transforming, analyzing, visualizing, and saving data.
4.	Organize a small data analysis project using directories, paths, scripts, documentation, and a GitHub repository.
5.	Develop the conceptual vocabulary and troubleshooting skills needed to continue learning programming independently and to evaluate code generated by large language models.
