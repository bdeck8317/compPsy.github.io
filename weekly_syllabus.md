Introduction to Data Science for Psychology & Brain Science
Syllabus & Course Structure

Unit 1: Ground Floor Concepts
Weeks 1–2
Introduction to the basic logic of programming and computing environments. Students learn what code is, how scripts are executed, how programming languages interact with the computer, and how to set up the basic tools needed to work in R or Python.
Topics include:
•	Introduction to programming environments
•	Software installation and setup
•	Scripts, commands, comments, and interpreters
•	Files, folders, paths, and directories
•	What it means to “think like a data scientist”
•	How programming supports reproducible research

Unit 2: Programming Essentials
Weeks 3–5
Introduces the core building blocks of programming. Students learn basic syntax and practice working with objects, data structures, functions, packages, and indexing. The emphasis is on understanding what code is doing rather than memorizing every command.
Topics include:
•	Basic syntax in R and Python
•	Variables and objects
•	Data types and data structures
•	Vectors, lists, arrays, data frames, and dictionaries
•	Packages and libraries
•	Functions and arguments
•	Indexing, subsetting, and filtering
•	Common errors and basic debugging strategies

Exam 1:
Students complete an exam assessing their ability to interpret basic code, identify core programming concepts, understand simple scripts, and read code examples in both R and Python. Students are expected to read, but not necessarily write, code in the language they did not choose for assignments.

Unit 3: Data Management and Processing
Weeks 6–7
Focus on working with data in ways that are common in psychology and brain science. Students practice importing datasets, inspecting their structure, cleaning and transforming variables, performing simple analyses, and generating basic visualizations.
Topics include:
•	Importing and saving data
•	Inspecting datasets
•	Basic data hygiene and preprocessing
•	Missing values and variable types
•	Data transformation
•	Simple descriptive statistics
•	Basic statistical tests
•	Basic plotting and visualization

Unit 4: Project Organization and Reproducibility
Week 8
Focuses on organizing data science projects so that analyses are easier to understand, reproduce, and share. Students learn how to structure project folders, use relative paths, document their work, and upload a project to GitHub.
Topics include:
•	Organizing directories and project folders
•	Relative versus absolute paths
•	README files and documentation
•	Saving scripts, data, outputs, and figures
•	Introduction to GitHub as a project repository
•	Reproducible research practices

Unit 5: Final Project Workshop and Submission
Weeks 9–10
The final weeks are devoted to applying course concepts in a small independent data analysis project. Students write a simple, well-commented script using either R or Python and organize the full project in a GitHub repository.

Final Assignment
For the final assignment, students write a simple script analyzing a dataset of their choosing. The project should demonstrate that students can organize, document, and execute a basic data analysis workflow.
The final project must include:
•	A clearly organized project folder
•	A dataset
•	A well-commented R or Python script
•	Appropriate use of directories and paths
•	At least three imported packages or libraries
•	At least two original user-written functions
•	At least four data transformations
•	Basic data preprocessing or hygiene
•	One simple statistical analysis
•	One data visualization
•	A README file explaining the project, files, and workflow
•	A GitHub repository containing the full project

The goal of the final assignment is not to produce a sophisticated analysis, but to demonstrate that students understand how to organize and execute a basic, reproducible data analysis workflow.
